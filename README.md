# Jermute Moraes Advocacia — novo site

Migração dos sites atuais em WordPress (`jermute.adv.br` e subdomínios por área)
para um **site único** em `jermute.adv.br`, com nova estrutura, nova identidade
visual e novo banco de dados.

> Status: **planejamento** — desenvolvimento ainda não iniciado.

## Stack

- **Front-end:** Next.js (App Router) + TypeScript + Tailwind
- **Banco / Auth / Storage:** Supabase
- **Deploy:** Vercel
